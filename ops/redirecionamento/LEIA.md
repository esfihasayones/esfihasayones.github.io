# Redirecionamento do endereço antigo

Estes dois arquivos (`index.html` e `404.html`) são o conteúdo de um repositório
novo e público chamado `esfihasayones.github.io`, na conta `esfihasayones`.
Ele existe só para que quem tiver o link antigo (Instagram, camiseta, conversas)
caia em `https://esfihas.sayones.com.br`, mantendo o caminho.

O repositório do site (`esfiharia`) fica privado e não publica nada no GitHub
Pages. Por isso este precisa ser um repositório à parte, com o nome
`esfihasayones.github.io`, para o GitHub Pages servir na raiz.

Como criar: veja o passo 8 de `ops/PASSOS-NO-PAINEL.md`. Copie os dois arquivos
para a raiz do repositório novo, faça commit na `main` e ligue o Pages
(Settings, Pages, branch `main`, pasta raiz).
